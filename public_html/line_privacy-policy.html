プライバシーポリシー

1. 個人情報の取り扱いについて

BE_SIDE コーチング（以下、「当社」）は、お客様の個人情報保護の重要性について認識し、個人情報の保護に関する法律（個人情報保護法）に基づき、以下のプライバシーポリシーを定め、これを遵守することで、お客様の個人情報の適切な取り扱い・保護に努めます。

2. 収集する個人情報の範囲

当社は、以下の個人情報を取得・利用させていただきます：

  • 氏名
  • メールアドレス
  • 電話番号
  • LINE ID
  • その他、当社サービス提供に必要な情報

3. 個人情報の利用目的

収集した個人情報は、以下の目的で利用いたします：

  1. コーチングサービスの提供
  2. お客様からのお問い合わせ対応
  3. サービスに関する情報提供
  4. マーケティング分析
  5. サービス品質向上のための調査・分析

4. 個人情報の第三者提供

当社は、以下の場合を除き、お客様の同意なく個人情報を第三者に提供することはありません：

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要な場合
  3. 公衆衛生の向上または児童の健全な育成の推進のために必要な場合
  4. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合

5. 個人情報の管理

当社は、個人情報の正確性を保ち、これを安全に管理いたします。個人情報の紛失、破壊、改ざん、漏洩などを防止するため、適切なセキュリティ対策を実施いたします。
